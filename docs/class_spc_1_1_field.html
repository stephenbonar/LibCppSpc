Detailed Description

Represents a binary data field in an SPC file.

The Spc::Field is meant for reading and writing individual fields from and to an SPC file. It is an extension of Binary::RawField that adds labels and offsets for formatting and locating the field. All fields in an Spc::DataStructure are expected to inherit from this class.
