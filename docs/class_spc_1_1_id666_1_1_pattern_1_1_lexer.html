Detailed Description

Responsible for tokenizing pattern strings.

The Lexer class takes a file name pattern string and breaks it down into individual tokens for further processing.

Invariant
Tokens returned in sequential order.
Tokens never skip or repeat.
End token is returned when the end of the pattern is reached.
