Detailed Description

Parses pattern tokens into a syntax tree of pattern nodes.

A file name pattern is first tokenized by the Lexer into a sequence of tokens. The Parser takes those tokens and parses them into a syntax tree of Node objects. The Spc::File class can then use the syntax tree to generate file names according to the pattern or extract values from the file name into the tag fields.

Invariant
The parser does not modify the tokens or their order.
