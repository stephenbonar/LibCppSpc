Detailed Description

Represents an Spc::NumericField formatted as binary by default.

This class is a specialization of Spc::NumericField that is always treated as containing a binary representation of a number. It provides methods for converting the field's data to and from a binary string representation such as "00100101". It is used for representing fields that should be interpreted as binary numbers, such as flags or bitmasks.

Invariant
The field's data is always treated as binary representation.
