◆ TagType

enum class Spc::Id666::TagType
strong

Represents the type of the ID666 tag.

Enumerator
Binary 

The tag has binary representation of numeric values.

Text 

The tag has text representation of numeric values.

TextMixed 

The tag has text offsets, but some numeric values are binary.
