Lib\+Cpp\+Spc is a modern, cross-\/platform C++ library for reading, writing, and manipulating SNES SPC music files ({\ttfamily .spc}) and their ID666 metadata tags.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md__r_e_a_d_m_e_autotoc_md1}

\begin{DoxyItemize}
\item Read and write SPC file data, including header, tag, and audio memory.
\item Read and write ID666 metadata (song title, game title, artist, track/\+disc, timing, and more).
\item Support pattern-\/based metadata/\+filename conversion with {\ttfamily Tag\+To\+File\+Name(pattern)} and {\ttfamily File\+Name\+To\+Tag(pattern)}.
\item Support extended ID666 tag structures.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{md__r_e_a_d_m_e_autotoc_md2}

\begin{DoxyItemize}
\item C++17-\/compatible compiler
\item CMake 3.\+10+
\end{DoxyItemize}
