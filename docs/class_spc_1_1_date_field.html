Detailed Description

Represents a field containing a date in an SPC file.

Date dumped can either have a text or binary representation. This field can determine which representation is used and output the date in the correct format based on the representation.

Invariant
The field's data is always treated as a date representation.
The field's data is always 11 bytes in size.

◆ IsText()

virtual bool Spc::DateField::IsText ( ) const
overridevirtual

Determines if all bytes in the field are ASCII numbers.

The field is most likely to contain a text representation if all bytes contain the ASCII characters '0' - '9' or binary 0. This is not 100% accurate detection as a binary value could conincidentally be the same as the ASCII codes for '0' - '9'. However, if this method returns false, it is almost a guarantee the field contains binary data.

Returns
True if no non-ASCII characters are found, otherwise false.
