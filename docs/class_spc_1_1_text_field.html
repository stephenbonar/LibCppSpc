Detailed Description

Represents a field containing text in an SPC file.

Texts fields are to be used for fields that are guaranteed to contain strings of ASCII text. They should not be used for fields that can contain text or binary representations of numbers.

Invariant
Size > 0.
The field's data is always treated as a string of text.
Setting string values will always fit the available size.
ToString() always returns a null terminated string.
