Detailed Description

Represents a field containing the track number in an SPC file.

The track field is a special type of numeric field that contains the track number of the song. It is unique in that it can contain a suffix character in addition to the track number. For example, a track field could contain the value "2a", where '2' is the track number and 'a' is the suffix.

Invariant
Field data is a valid track number with optional suffix.
The track number is between 0 and 99.
The first byte of data is the suffix character.
The second byte of data is the track number.
ToString() returns the track number followed by the suffix
