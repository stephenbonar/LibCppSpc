Detailed Description

Represents a field containing a number in an SPC file.

Depending on the format of the SPC file, numeric fields can either have a text or binary representation of the number. This class represents a numeric field that can contain either a text or binary representation of a number and have some detetion capabilities to determine what kind of representation is contained within. It also provides different methods of retrieving the value depending on if the field should always interpret the data as binary or if it could possibly contain both.

Invariant
Size must be > 0.
The field data must always represent a valid number.
Setting value will always use correct format based on type.
ToString() will always format correctly based on type.

◆ IsText()

virtual bool Spc::NumericField::IsText ( ) const
virtual

Determines if all bytes in the field are ASCII numbers.

The field is most likely to contain a text representation if all bytes contain the ASCII characters '0' - '9' or binary 0. This is not 100% accurate detection as a binary value could conincidentally be the same as the ASCII codes for '0' - '9'. However, if this method returns false, it is almost a guarantee the field contains binary data.

Returns
True if no non-ASCII characters are found, otherwise false.
